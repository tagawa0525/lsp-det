# ADR 索引

ADR は採用後に本文を書き換えない。決定が覆ったときは新しい ADR を書き、古い ADR は状態行に「廃止」と置き換え先を記す。本索引は各 ADR について**生きている決定だけ**を列挙する。廃止された決定を読む必要はない。経緯を知りたいときだけ本文に当たる。
