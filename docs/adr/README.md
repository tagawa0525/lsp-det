# ADR index

[日本語](README.ja.md)

An ADR's body is not rewritten once adopted. When a decision is overturned, a new ADR is written and the old ADR's status line is replaced with "superseded" and a pointer to the replacement. This index lists, for each ADR, only the **decisions still alive**. There is no need to read a superseded decision. Consult the body only to learn the context.

Each ADR is in Japanese.
